Only problems seen on current builds are listed here. Problems that have been fixed are under [Notable fixes](/wiki/neutron/fixes/notable-fixes/).

## All apps

- **At a display scale that isn't a Windows step, parts of the interface land slightly off.** In Premiere Pro, the marked in/out range on the timeline ruler drifts to the right of the selection. Set your desktop to 100, 125, 150, 175, 200, 225, 250 or 300% (see [Choosing a display scale](/wiki/start/basics/display-scale/)). This comes from inside the app, not from Neutron.

## Animate

- **The home screen is blank.** Start from File → New or File → Open. This is Adobe's own bug: the home screen is blank on Windows too.
- **File → New does nothing for about the first 15 seconds after launch.** Wait, or try again after a moment. This comes from inside the app, not from Neutron.

## Lightroom Classic

- **The interface takes several seconds to paint in when the app starts.** Wait for it to finish. This comes from inside the app, not from Neutron.

## Premiere Pro

- **Fast wheel-scrubbing on the timeline feels a bit late and jumpy.** No workaround yet.
