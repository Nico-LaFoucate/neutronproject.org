sub: Problems you’d have seen on earlier builds, one line each.

Where a fix has a full write-up, it’s linked.

- **All apps** — Dragging files in from the Linux file manager didn’t work. Fixed.
- **All apps** — Extension panels (CEP) didn’t show up in their dock. Fixed for most panels.
- **All apps** — A Wine Mono installer popup appeared. Fixed.
- **aescripts + aeplugins manager** — It crashed when started. Fixed. Installing plugins through it hasn’t been tested yet.
- **After Effects** — The composition viewer stayed blank. Fixed.
- **After Effects** — Creating a new composition failed with a direct2d drawbot error. Fixed.
- **After Effects** — The splash screen never appeared. Fixed.
- **After Effects 2026** — The composition viewer didn’t render, because the display setting was written to the preferences file it doesn’t read. Fixed.
- **After Effects and Media Encoder** — Short labels wrapped onto a second line. Fixed.
- **Illustrator** — The whole window was sheared: the interface skewed a little further with every row. Fixed.
- **Illustrator and Animate** — The main window was a solid white block. Fixed.
- **Lightroom Classic** — Photo → Edit In took about ten seconds to open. Fixed: [the ten-second menu](/wiki/neutron/fixes/edit-in-lag/).
- **Lightroom Classic** — Edit In → Photoshop was grayed out. Fixed.
- **Lightroom Classic** — AI Denoise and AI masking didn’t work. Fixed.
- **Lightroom Classic** — Zoom and the Develop sliders lagged and moved in steps. Fixed.
- **Lightroom Classic** — The filmstrip stopped scrolling partway through a large catalog. Fixed.
- **Lightroom Classic** — The Copy Settings dialog showed a blank list instead of checkboxes. Fixed.
- **Lightroom Classic** — The Develop histogram was a flat green block with no channel curves. Fixed.
- **Lightroom Classic** — The filmstrip’s shading floated over other apps’ windows. Fixed.
- **Photoshop** — Drawing on the canvas lagged. Fixed.
- **Photoshop** — Menu item names overlapped their keyboard shortcuts. Fixed.
- **Photoshop** — Scroll bars flashed the wrong color on hover. Fixed.
- **Photoshop 2026** — A maximized window sat a few pixels off. Fixed.
- **Premiere Pro** — Exports needed a separate muxing step before they were valid MP4 files. Fixed.
- **Premiere Pro** — Scrubbing the timeline lagged. Fixed.
- **Premiere Pro** — Rounded buttons and scroll bars were drawn misshapen. Fixed.
- **Premiere Pro** — The home screen showed only gray placeholders. Fixed.
- **Premiere Pro** — The menu-bar dropdowns (File, Edit…) had their bottom cut off. Fixed.
- **Premiere Pro** — Timeline clips and other parts of the interface vanished, often on hover. Fixed.
- **Premiere Pro** — FabFilter and other VST plugin windows sank behind the Program Monitor. Fixed.
- **Premiere Pro** — The timeline’s time ruler was missing. Fixed.
- **Premiere Pro** — Clicking back into Premiere from another app made it lose focus again. Fixed.
- **Premiere Pro** — The mouse pointer disappeared when moving into a menu. Fixed.
- **Premiere Pro** — One Backspace deleted two characters. Fixed.
